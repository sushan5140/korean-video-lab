# Haneul Video Lab

Persistent project memory and continuation repository for the Haneul Video Lab Korean-learning product.

## Official production site

https://korean-video-lab.vercel.app/

## Project identity

Haneul Video Lab is an independent Korean-learning product built around real Korean video content. It must remain separate from Haneul K-Drama Interactive and every unrelated project.

## Current product model

The learning experience is built directly around real video content and synchronized transcript cues. Existing functionality includes:

- video playback
- synchronized Korean captions
- English meaning/context
- cue navigation
- replaying individual lines
- Guess interactions
- Loop
- Practice
- Vocabulary / Words
- Explain
- learning checkpoints
- saved/pinned learning content
- progress-related interactions
- Micro Lessons
- Library
- learning journey navigation

## Design lock

The current UI is approved. Do not redesign or visually refine it unless explicitly requested.

Preserve:

- player layout
- browse experience
- caption interface
- side learning area
- bottom controls
- visual styling
- spacing
- interaction structure

Any new functionality must fit naturally inside the existing visual system.
