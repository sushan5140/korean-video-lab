# Haneul X Ambassador-only tools — 2026-09-19

Integrated into the existing code-scoped `/creators/` workspace, under the new **✦ Ambassador AI Factory** tab, visible to the creator assigned to the referral code and Haneul admins, not the learners.

- **OpenRouter BYOK**: Ambassador supplies their own `sk-or-...` API key and selects or enters a model ID. Key is kept in JS/browser input only, forwarded to `/api/ambassador-ai` in a request header over HTTPS, and is never written into Haneul's Supabase tables, localStorage or URLs. Disconnect clears JS and input; a reload clears the key. Provider may charge ambassador according to their model and plan. Existing learner AI remains on the separate Groq-based `/api/creator-ai`. `api/ambassador-ai.js` verifies the user's Google session through Supabase `haneul_creator_owner` **before** forwarding to OpenRouter, includes timeout and high-level provider errors without echoing key or account information.
- **AI Content Factory**: One generation returns carousel copy, short Reel script, social caption and a Korean community challenge. Topic, language difficulty, platform and optional authentic Korean caption excerpt provided by creator. Output editable, copyable and saveable as private draft, then shareable with referred community. Human review before publishing.
- **Quiz Battle Builder**: Generates 5 Korean multiple-choice questions and answer explanations from a supplied actual Korean excerpt (or original topic-based examples if no excerpt). Quiz is saved/shared as an educational text experience, **not** a scored multiplayer quiz with verified attempts.
- **Community Learning Doctor**: Receives only 3 code-scoped aggregate dashboard counts (referral members, completed challenge days, speaking weeks) and current weekly prompt. With zero activity, returns a starter plan instead of making up learners' mistakes or drop-off statistics.
- **YouTube Community Drops**: Creator pastes a new YouTube watch URL, short URL, Shorts URL or video ID with title/note. Publishing saves the ID and title only in an RLS-protected code-owned post and immediately shows a shareable card with thumbnail and watch link to referred learners on the existing Videos tab. It does not require a transcript; the original separate interactive Video-to-Lesson submission continues to require captions and quality checks. No fake audio synchronization.
- **Library**: `haneul_ambassador_posts` with RLS; no direct anon/authenticated table grants; `haneul_ambassador_save_post`, `haneul_ambassador_list_posts`, `haneul_ambassador_set_published` verify creator or referral membership via existing code-based functions. Max 150 saved posts per creator and JSON size limit 16k characters. Drafts visible only to creator/admin; published kits/quizzes/videos visible to referral members only.

**Owner preview**: Existing private paused `HNL-X-OWNER-PREVIEW-SIG00` retains admin access, seven Ready challenge videos and demo creator lesson. The ambassador tab should be visible there after deployment.

**Testing status**: SQL migration `haneul_ambassador_creator_posts_and_video_shares` applied; GitHub API and frontend scripts syntax checked and DOM id binding checked.
